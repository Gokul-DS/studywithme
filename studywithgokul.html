Cheat Sheet

Core formulas and rules — study this the night before your exam.

Conversion Rules

Decimal → Binary: Divide by 2, read remainders ↑
Decimal → Octal: Divide by 8, read remainders ↑
Decimal → Hex: Divide by 16, use A–F for 10–15
Binary → Octal: Group 3 bits from right
Binary → Hex: Group 4 bits from right
Binary → Decimal: Σ bit × 2position

Binary Arithmetic

Addition: 1+1 = 10 (write 0, carry 1)
Addition: 1+1+1 = 11 (write 1, carry 1)
Subtraction: 0-1 borrows from next column
1's complement: flip all bits
2's complement: 1's complement + 1
Used to represent negative numbers

BCD & Excess-3

BCD: each decimal digit → 4-bit binary
BCD is a weighted code
Excess-3: digit + 3 → 4-bit binary
Excess-3 is non-weighted, self-complementing
Example — 5 in XS3: 5+3=8 → 1000
Example — 9 in BCD: 1001

Boolean Algebra

SOP: OR of AND terms (minterms where output = 1)
POS: AND of OR terms (maxterms where output = 0)
Minterm: product term, output = 1 for ONE combo
Maxterm: sum term, output = 0 for ONE combo
n variables → 2n minterms & maxterms

K-Map Rules

Groups must be powers of 2: 1, 2, 4, 8…
Make largest possible groups
Groups can wrap around edges
SOP → group 1s | POS → group 0s
Larger group = fewer variables in term
Cells differ by only 1 bit (Gray code)

Quine-McCluskey Steps

1. Group minterms by number of 1s
2. Combine pairs differing by 1 bit → use '-'
3. Repeat until prime implicants found
4. Build prime implicant table
5. Find essential prime implicants
6. Select minimum cover
